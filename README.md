## 🚀 Featured Project

### 📱 PostPro — Social Media Content Companion

**PostPro** is a PHP and MySQL-based web application designed to
help users discover suitable captions, hashtags, and song suggestions
for social media posts based on their selected mood.

**Key Features**

- 📝 Mood-based caption suggestions
- #️⃣ Hashtag discovery for social media content
- 🎵 Mood-based song recommendations
- 🔐 User registration and login
- ⭐ Favourite content management

**Technology Stack:** PHP · MySQL · HTML · CSS · JavaScript
